About This App

This application was built to visualize global weather patterns in a simple, interactive way. The goal is to help users quickly understand how temperature varies across different regions of the world.

The data comes from external weather APIs that provide real-time and recent atmospheric data for cities worldwide.

To use the app, rotate the globe and hover over points to view detailed weather information for each location.

This visualization helps users identify global trends, compare climates, and spot extreme temperature regions.
